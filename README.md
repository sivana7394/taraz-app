# تراز — حسابداری مشارکت ساخت‌وساز

اپ اندرویدی (Flutter) برای ثبت و همگام‌سازی آنی هزینه‌های یک پروژهٔ ساخت بین دو طرف
(مثلاً ۳ دانگ / ۳ دانگ)، با عکس رسید، تاریخ شمسی، داشبورد، تراز بدهکار/بستانکار و خروجی اکسل/PDF.

## ساخت فایل نصبی (APK) با GitHub Actions

1. این مخزن را در گیت‌هاب بسازید و فایل‌ها را بالا بریزید (شاخهٔ `main`).
2. در گیت‌هاب: **Settings → Secrets and variables → Actions → New repository secret**
   - Name: `KEYSTORE_PASSWORD`
   - Secret: یک رمز قوی دلخواه (این رمز فایل امضای اپ را محافظت می‌کند؛ آن را جایی امن نگه دارید).
3. با هر push، کار `Build APK` اجرا می‌شود (حدود ۱۰ دقیقه). نتیجه:
   - **Releases** → فایل `taraz-v1.0.N.apk`
   - پوشهٔ `ci/` → لاگ‌ها (`build.log`, `analyze.log`, `test.log`) و اسکرین‌شات صفحات (`ci/screens/`)
   - فایل `keystore/taraz.jks` در اولین ساخت ایجاد و به مخزن اضافه می‌شود تا نسخه‌های بعدی با همان امضا ساخته شوند.

## راه‌اندازی داخل اپ

- مدیر پروژه: «ساخت پروژهٔ جدید» → راهنمای ساخت پروژهٔ رایگان Firebase داخل اپ → جای‌گذاری تنظیمات → اپ یک «کد دعوت» می‌سازد.
- شرکا: «پیوستن با کد دعوت».
- «حالت نمایشی» برای دیدن اپ با داده‌های نمونه، بدون اینترنت.

## ساختار

- `lib/core` — فرمت فارسی (ارقام، تاریخ شمسی، عدد به حروف)، پوسته، پردازش عکس
- `lib/data` — مدل‌ها، Firestore/حالت نمایشی، محاسبهٔ تراز، خروجی‌ها، تنظیمات محلی
- `lib/ui` — راه‌اندازی، داشبورد، هزینه‌ها، گزارش‌ها، تنظیمات
- `tools/` — اسکریپت‌های CI (تنظیم پوشهٔ android، امضا)
- `test/` — تست‌های منطق و اسکرین‌شات
